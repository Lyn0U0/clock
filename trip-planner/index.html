點地圖或搜尋加入景點，拖曳或用箭頭調整順序。

    設定 Google Maps 金鑰

    1. 到 Google Cloud Console 建立 API 金鑰。
    2. 啟用 Maps JavaScript API 與 Routes API（交通時間）；搜尋地點、點地圖上的店家自動帶入名稱，需再啟用 Places API (New)。
    3. 在金鑰的「應用程式限制」選「網站」，加入 lyn0u0.github.io/*。

    金鑰只會存在這台瀏覽器。要讓所有人打開就能用，請把金鑰填進 app.js 的 GOOGLE_MAPS_API_KEY。
